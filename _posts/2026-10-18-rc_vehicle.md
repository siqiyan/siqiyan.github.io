![JRBot Side](/assets/img/rc_vehicle_main.jpg)

This robot has modified control curcuit and customized firmware. It
is built for long range outdoor exploration tasks with both manual control and
automatic navigation modes.

It is based on Arduino Nano microcontroller and has GPS sensor, compass and
wheel encoder for self-localization. The nRF24 module provides approximately 1km 
control range which is sufficient for its outdoor control use cases.

![JRBot Front](/assets/img/rc_vehicle_front.jpg)

The remote controller for the vehicle also equipted with the same nRF24 module,
joystick module and 2004LCD display.

![JRBot Front](/assets/img/rc_vehicle_remote.jpg)
